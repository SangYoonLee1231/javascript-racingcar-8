## 문제 분석 및 설계

### 프로그램 전체 흐름

1. 사용자에게 경주할 자동차 이름 목록을 입력받는다.

   - 예: pobi, woni, jun

2. 자동차 이름들을 검증하고, 각 자동차 객체(또는 기록 구조)를 생성한다.
3. 사용자에게 시도할 횟수를 입력받는다.

   - 예: 5

4. 라운드를 1번부터 N번까지 반복하며 아래 과정을 수행한다.

   - 각 자동차에 대해 전진 여부를 랜덤으로 결정한다.
   - 전진 조건(0~9 중 뽑은 랜덤 값이 4 이상이면 전진)에 따라 자동차의 위치를 갱신한다.
   - 해당 라운드의 결과를 출력 형식에 맞게 기록/출력한다.

5. 반복이 모두 끝나면 가장 멀리 간 자동차(들)를 찾아 우승자를 결정하고 출력 형식에 맞게 출력한다.
6. 잘못된 입력이 들어온 경우, [ERROR] ... 메시지를 출력하고 예외를 던진 뒤 프로그램을 종료한다. (추가 입력 받지 않음)

<br/>

### 기능 목록 정리

- 자동차 이름 입력받기 및 파싱

  - 쉼표(,)로 구분된 문자열을 받아 자동차 이름 리스트로 변환한다.
  - 공백이 있을 경우(trim 등) 정리 기준은 스스로 정하되, 일관되게 처리한다.
  - 예외 상황(빈 이름 등) 검증한다.

- 자동차 이름 검증

  - 각 이름은 길이가 1 이상 5 이하인지 확인한다.
  - 빈 문자열 또는 6자 이상 이름 존재 시 에러를 던진다.
  - 중복 이름 허용 여부는 명시돼 있지 않으므로 기본적으로 허용한다고 가정한다.
  - 유효하지 않은 경우 [ERROR] ... 메시지와 함께 예외를 발생시키고 프로그램 종료.

- 시도 횟수 입력받기 및 검증

  - 사용자의 입력을 정수로 변환한다.
  - 정수가 아닐 경우 에러.
  - 0 이하(음수 또는 0)일 경우 에러. (횟수는 최소 1회 이상이라 보는 게 자연스럽다.)
  - 에러 시 [ERROR] ... 메시지와 함께 예외 발생 후 종료.

- Car 객체(또는 Car 데이터 구조) 생성

  - 각 자동차 이름에 대해 `{ name, position: 0 }` 형태의 상태를 준비한다.
  - position은 숫자 0으로 초기화.

- 한 라운드 진행 로직 구현

  - 자동차마다 `MissionUtils.Random.pickNumberInRange(0, 9)` 호출.
  - 4 이상이면 `position += 1`.
  - 라운드가 끝난 뒤 각 자동차의 "이름 : ----" 형태 문자열을 얻을 수 있어야 한다.

- N번 라운드 반복 & 라운드별 결과 출력

  - “실행 결과”를 한 번 출력한다.
  - 라운드마다 모든 자동차의 현재 상태를 출력한다.
  - 라운드 사이에 개행 라인이 필요한지 여부를 예시 출력과 동일하게 맞춘다.  
    (예시에 보면 각 라운드 결과 사이에 빈 줄이 하나씩 들어간다.)

- 우승자 계산

  - 가장 `position`이 큰 수를 구한다.
  - 그 `position`을 가진 자동차 이름들을 전부 수집한다.
  - 여러 명일 경우 쉼표(`,`)로 `join`한다.

- 최종 우승자 출력
  - "최종 우승자 : {이름1, 이름2,...}" 형식으로 출력한다.
